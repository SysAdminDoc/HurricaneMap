Accessibility features summary

  • Non-color encoding: Marker dash patterns distinguish TS (solid), Cat 1-2 (dashed), Cat 3-4 (dotted), Cat 5 (mixed)
  • Data table alternative: "Table view" button renders all filtered landfalls in a sortable, keyboard-navigable HTML table
  • Reduced motion: OS preference and in-app toggle suppress all animations, glyph rotation, and map flyTo transitions
  • High contrast: WCAG AAA 7:1+ contrast mode with bolder fonts and enhanced focus rings
  • Colorblind palette: ColorBrewer YlOrRd sequential palette distinguishable under protanopia, deuteranopia, and tritanopia
  • Keyboard navigation: All panels, dialogs, search, settings, comparison, and table view fully keyboard-operable
  • Screen reader support: ARIA landmarks, live regions, semantic headings, and labeled controls throughout
  • Internationalization: English, Spanish (ES-LA), and Haitian Creole locales with browser auto-detection
  • Touch targets: WCAG AAA 44x44px minimum on mobile (720px and below)

Known limitations

  • Leaflet map markers (SVG circles) are not individually keyboard-focusable. The data table provides an equivalent keyboard-navigable alternative.
  • 3D globe visualization (Cesium) has limited accessibility — it is an opt-in feature and the 2D map is the default.
  • Print stylesheet hides interactive elements; printed output is a snapshot of the last-rendered map state.
